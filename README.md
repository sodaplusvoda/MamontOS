# MamontOS x86_64

![MamontOS Banner](assets/mamontlogo.png)

Это моя учебная 64-битная Операционная Система написанная на Ассемблере NASM и C.

Проект базируется на концепции "недо-микроядра" или же гибридного ядра. Цель - оставить в пространстве ядра только критически важные функции управления системой, но оставить драйвера для дисков и файловую систему.
Все остальные сервисы (драйвера периферии, терминал, и возможно даже GUI, если его добавлю) реализуются как изолированные программы, загружаемые с диска.

**Что уже реализовано:**
* **Загрузка:** Загрузчик с поддержкой Multiboot2.
* **Графика:** Работа с Framebuffer (разрешение 800x600, 32-битный цвет). Шрифт для текста брал с https://github.com/novariaos/novariaos-src.
* **System:** Настроен GDT.
* **Прерывания:** Обработка исключений процессора и аппаратных прерываний через PIC (в планах переход на APIC).

### Сборка
Для сборки требуется `gcc` (x86_64-elf), `nasm`, `binutils`, `grub`, `libisoburn`, `mtools` и `qemu` для запуска.
